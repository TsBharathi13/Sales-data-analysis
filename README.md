# 🛒 Superstore Sales Data Analysis

### 📊 Project Overview
End-to-end Data Analysis project on Sample Superstore dataset to identify sales trends, profit drivers, and business insights. Focused on delivering actionable insights for business growth.

### 🛠️ Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **SQL:** Data querying and business insights
- **Power BI:** Interactive Sales Dashboard
- **Tools:** Jupyter Notebook, GitHub

### 📁 Files in this Repository
- `FinalProject.ipynb` - Complete EDA and visualizations in Python
- `superstore_analysis.sql` - SQL queries for sales & profit analysis
- `Sales_Dashboard.pbix` - Power BI interactive dashboard
- `SampleSuperstore.csv` - Dataset (9,994 orders)
- `Sales_Analysis_Project_Report.docx` - Detailed project report

### 🔍 Key Analysis
- Sales & Profit by Region, Category, and Segment
- Customer Segmentation & Buying Behavior
- Profitability Analysis & Loss-making Products
- Monthly & Yearly Sales Trends
- Power BI Dashboard with KPIs

### 💡 Key Insights
- Identified top profitable regions and product categories
- Found correlation between discount and profit loss
- Created interactive dashboard for management decision-making

### 🚀 How to Run
1. Clone the repo
2. Open `FinalProject.ipynb` in Jupyter
3. Open `Sales_Dashboard.pbix` in Power BI Desktop
4. Run SQL queries from `superstore_analysis.sql`

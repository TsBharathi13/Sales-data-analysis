# Superstore Sales Data Analysis

## 📊 Project Overview
End-to-end Data Analysis project on Sample Superstore dataset to identify sales trends, profit drivers, and business insights for TCS NQT Portfolio.

## 🔧 Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (for data querying)
- Jupyter Notebook
- GitHub

## 📁 Files
- FinalProject.ipynb - Complete EDA and visualizations
- superstore_analysis.sql - SQL queries for business insights
- SampleSuperstore.csv - Dataset

## 🔍 Key Analysis
- Sales & Profit by Region, Category, Segment
- Customer segmentation
- Top performing products
- Year-over-Year growth trends

## 📈 Insights
- Identified high-profit vs low-profit categories
- Regional performance comparison
- Recommendations for business growth
